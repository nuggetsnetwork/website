Conventions:

  • Say where each fact came from: a URL with the date it was read, or "from memory". Do not write a source down unless it was actually read.
  • "Not verified" is a list, not an apology. It tells the next session what to check first.
  • An exclusion needs a reason ("held the city under a month", "ruled from elsewhere", "no surviving buildings").
  • Photo credits live in src/data/images.json (one entry per monument: author, licence, source page). These notes only cover decisions about photos.
